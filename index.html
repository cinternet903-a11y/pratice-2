This is my CSS Box Assignment. In this assignment, I am using margin, padding, border, overflow and different colors to design a beautiful webpage.

CSS stands for Cascading Style Sheets. It is used to style HTML webpages. With CSS, we can change colors, font sizes, backgrounds, borders and layouts.

The box model contains content, padding, border and margin. Padding creates space inside an element, while margin creates space outside an element.

The overflow property controls what happens when content is bigger than its container. Here I am using overflow-y scroll to scroll the text vertically.

CSS makes websites attractive and easy to use. We can also use images, circles and product cards to improve the design of our webpage.
